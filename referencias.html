Da prévia à publicação

GitHub e Google Sites:
papéis diferentes.

O repositório Wellmarket no GitHub guarda os arquivos do site. A versão pública é publicada pelo GitHub Actions no GitHub Pages, sem compilação nem servidor.

O Google Sites não importa um repositório como site pronto. Para preservar o visual, o caminho é hospedar o site e incorporar seu endereço no Google Sites, desde que a hospedagem permita a incorporação. Outra opção é recriar o conteúdo no editor do Google Sites, com menos liberdade visual.

A imagem do mercado é ilustrativa; não representa uma unidade implantada. O formulário de avaliação não coleta dados: os canais de contato abrem WhatsApp ou e-mail.
